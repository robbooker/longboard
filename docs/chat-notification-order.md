# Unified chat notification order

Ticket `fc8dd4d2-d23e-4310-a037-61f714b00c63`, approved revision 2. Published integration base: `3bea0f1c019d5492ad9a27f83c6e934c3cf3f5e5`.

The chat bell displays room alerts, grouped direct messages, and reactions in one newest-first list. A pure helper copies the supplied samples into a discriminated union, compares valid `createdAt` instants descending, and breaks equal-time ties by category-prefixed ID. Missing or invalid legacy dates follow all dated entries with the same deterministic key ordering. Read state never affects position. The helper does not mutate inputs, expand server samples, create extra requests, or derive counts/cursors from listed rows.

Unread rows now have a theme-aware tinted background and left accent, analogous to feature notifications. Read rows remain visible with their existing lighter type and Read label. Only unread entries offer Mark as read. Successful reconciliation changes the highlight/control without moving the row. Unread context text uses the normal theme text color so reply/reaction context remains readable over the tint; read context retains its original muted color.

Category headings are removed. Existing full totals remain in the summary; category-specific empty or unavailable-sample notices remain below the list. Grouped DMs still display the server's latest incoming message per conversation. Complete unread totals, personal pinned-DM counts, room markers, independent observed event cursors, exact read bodies, errors, reply preferences, navigation targets and owner fences are unchanged. No SQL, API, authorization, push, hook, or coordinator implementation changes are included. The release plan is migration-free.
